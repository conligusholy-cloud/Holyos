Facebook / Meta Ads – centrální napojení

Jeden přístupový token pro všechny funely a startovací body. Potřebuješ System User token z Meta Business Manageru (Nastavení firmy → Uživatelé → Systémoví uživatelé → Vygenerovat token, oprávnění ads_read + read_insights, přiřazené reklamní účty). Token se ukládá jen na serveru. V editoru funelu pak u startovacího bodu jen vybereš reklamní účet a kampaň.

📨 Amazon SES – hromadná brána (env-first)

Levné hromadné odesílání (~0,10 $ / 1 000 e-mailů) se sledováním otevření, prokliků a bounců přes SNS webhook a automatickým odhlašováním problémových adres. Nastavuje se proměnnými prostředí v Railway (přežije reset DB): SMTP_HOST, SMTP_PORT, SMTP_SECURE, SMTP_USER, SMTP_PASS, SMTP_FROM, SES_CONFIGURATION_SET, PUBLIC_BASE_URL. Přes SES chodí jen e-maily od adresy SMTP_FROM – pro funely ji zvol jako „Výchozí odesílatel pro funely“ výš (dokud to neuděláš, nic se přes SES naostro neposílá).

✉️ E-mailová brána (SMTP) – Best Series 2.0

Vlastní SMTP brána pro e-maily z funelů (Brevo, Amazon SES, Microsoft 365…). Když je nastavená, e-maily od jejího odesílatele chodí přes ni (přednost před M365 Graph). Heslo se ukládá na serveru a nikdy se nezobrazuje.

Načítám…
Brevo (doména bestseries2.cz): Host smtp-relay.brevo.com, Port 587, SSL/TLS nezaškrtávat. Uživatel = přihlašovací e-mail Brevo účtu (SMTP Login), Heslo = SMTP klíč z Brevo (Settings → SMTP & API → záložka SMTP → Generate a new SMTP key). Odesílatel musí být na ověřené doméně.
Amazon SES (nejlevnější, ~0,10 $ / 1 000 e-mailů): Host email-smtp.eu-central-1.amazonaws.com (podle regionu), Port 587, SSL/TLS nezaškrtávat. Uživatel + Heslo = SMTP credentials z SES (SES → SMTP settings → Create SMTP credentials). Nutné: ověřit doménu (DKIM), zažádat o production access a Odesílatele mít na ověřené doméně.
Microsoft 365: host smtp.office365.com, port 587, SSL/TLS nezaškrtávat. Na schránce povolit „Authenticated SMTP"; při MFA použít heslo aplikace.
