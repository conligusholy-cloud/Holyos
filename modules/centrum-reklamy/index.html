Facebook / Meta Ads – centrální napojení

Jeden přístupový token pro všechny funely a startovací body. Potřebuješ System User token z Meta Business Manageru (Nastavení firmy → Uživatelé → Systémoví uživatelé → Vygenerovat token, oprávnění ads_read + read_insights, přiřazené reklamní účty). Token se ukládá jen na serveru. V editoru funelu pak u startovacího bodu jen vybereš reklamní účet a kampaň.

📋 Leady z Facebooku napřímo

HolyOS si stahuje odeslané rychlé formuláře přímo z Facebooku – bez Make.com. Napojení přes tvůj Facebook účet (jsi správce stránky): klikni Připojit Facebook účet, potvrď oprávnění a HolyOS si uloží trvalé přístupy ke stránkám. Leady se zakládají stejně jako z webhooku – obchodník podle mapování formulářů, bez duplicit.

✉️ E-mailová brána – odesílatelé

Schránky, ze kterých HolyOS umí posílat zprávy (akční prvek „E-mail" ve funelu). Odesílá se přes Microsoft 365 (Graph send-as), záložně SMTP. Schránka musí existovat v M365 a být povolená pro aplikaci HolyOS. Adresy se berou z prostředí serveru; vlastní schránku lze přidat níže.
